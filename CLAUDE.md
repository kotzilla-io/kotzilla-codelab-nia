# Now in Android: Kotzilla Codelab

This app is monitored by the Kotzilla Platform. For any performance, crash, or Koin
dependency-injection investigation, use the **Kotzilla MCP server** as the primary evidence source:
query the detected issues, issue context (dependency trees, timings, stack traces), screen
performance, and fix guidance before reasoning from the code alone.

See [`AGENTS.md`](AGENTS.md) for project architecture, modules, and build/test commands.
